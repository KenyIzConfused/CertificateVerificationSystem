Template Placeholders Guide

Use these placeholders in your .docx template. They will be replaced with attendee data automatically.

{name} Attendee's full name (alias: {fullName})
{course} Course or program name
{role} Attendee's role (e.g., Student, Speaker)
{dateAttended} Date the event was attended
{certificateId} Unique certificate ID
