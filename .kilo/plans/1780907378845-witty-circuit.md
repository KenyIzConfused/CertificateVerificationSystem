# Certificate Management System Plan

## Structure
```
/logIn/          - Login page (existing)
/SignUp/         - Admin registration
/EventCRUD/      - Create/read events & attendees
/Verify/         - QR certificate verification
```

## Features to Implement

### 1. SignUp Folder
- Create `SignUp/SignUpAdmin.html` + `.js`
- Form fields: Admin name, email, password
- **Use Firebase Authentication** (secure, password hashing handled)
- Redirect to `/EventCRUD/EventCRUD.html` after signup

### 2. Event CRUD Folder
- `EventCRUD/EventCRUD.html` + `.js`
- Form: Event title, Attendee name, Course, Role
- Firestore: `Certificates` collection (one document per attendee)
- Document fields: uuid, eventName, attendeeName, course, role, dateAttended

### 3. QR Code Generation
- Add "Close Event" button to CRUD
- Generate UUID per certificate
- Use QR library (qrcode.js)
- QR links to `/Verify/VerifyCertificate.html?uuid=<uuid>`

### 4. Verification Page
- `Verify/VerifyCertificate.html` + `.js`
- Read UUID from URL params
- Query `Certificates` collection
- Display: name, course, role, date

## Confirmed Requirements
1. ✅ Firebase Auth for SignUp
2. ✅ Separate documents in same `Certificates` collection
3. ✅ Full CRUD (including delete for forfeits/absences)
4. ✅ Redirect to EventCRUD after login/signup
5. QR codes generated when admin closes event
